工装管理说明

工装全生命周期管理要求

本说明与系统配套使用——工装台账、借用、检定、报废等记录均在系统内相应模块办理。

一、目的与适用范围

目的：及时提供合格的工装，确保产品生产顺利开展，提高产品质量与生产效率，使产品符合规定要求。

适用范围：工装的设计、制造、验证、使用和维护管理。

二、工装定义

工装即工艺装备，指产品生产过程中自主设计制造的定位、防护、转运、性能测试、专用工具、夹具等装备的总称；是为提高产品质量与工作效率，使产品的尺寸、性能满足工艺、技术标准而使用的辅助工具。

三、工装分类与检定周期

类别判定规则推荐使用寿命检定周期
A ① 产品中的关键工序、关键特性；② 存在安全隐患；③ 维修周期超过 3 天。
如：影响产品性能、安全、寿命等问题的工装。		 2 年 6 个月 / 次
B ① 产品中的安装、配合尺寸；② 维修周期超过 1 天。
如：保证工序间装配尺寸或外部安装尺寸的工装。		 2 年 1 年 / 次
C 简易工装、辅具，仅做台账管理。
如：转接头、封堵板、平台、转运车、设备装夹辅具等无尺寸要求、仅做辅助测试、自身无要求的工装。		 无 无

系统中的「等级」字段即对应本分类，由工艺部门确定。新增或修改等级时，系统按「入库时间」自动推算下次检定日期：A 级 +6 个月、B 级 +1 年、C 级不推算；A、B 两类可在侧边栏「A/B工装」页集中查看与筛选。

四、职责分工

中心 / 部门职责与权限
工艺部门 ① 发起工装需求流程；② 负责工装设计、图纸及其工艺资料生效，维护工装台账；③ 确定工装类别、寿命和检定周期；④ 若为 A、B 类工装，需工装设计人员组织评审；⑤ 参与工装的验收、报废；⑥ 定期对工装制作、使用情况进行汇总通报。
生产管理部 ① 按项目产品零件制作计划制定工装制作计划；② 完善台账相关信息；③ 管控工装零部件自制过程；④ 新作成品工装报检；⑤ 线边常用工装的维护、保养；⑥ 设置工装成品暂存区；⑦ 工装图纸受控、下发；⑧ 非项目工装按需求流程时间制定制作计划。
采购主管部门 ① 工装中的标准件、外购件采购。
质量主管部门 ① 负责工装零部件的关键尺寸检测、成品工装功能检定并对记录存档；② 负责按台账对 A、B 类工装进行周期性检定并记录存档；③ 负责对工装制作的首件产品进行尺寸、性能检测。
仓储物流部门 ① 办理工装出入库，并在台账上登记相关信息；② 入库工装的维护、保养及日常管理；③ 设立工装存放区；④ 启动工装报废申请流程。
其他部门 ① 根据需求登记台账并发起工装需求流程。

1. 工装编号

工装编号参照《产品图样编码方法》执行。

2. 工装需求

  • 现场各工位、工序提出需求前，须与本部门管理人员和责任工艺工程师充分评估，确认可行与必要，经部门经理审批后登记台账并发起工装需求流程。
  • 需求申请单与台账信息必须一致；工装设计人员按台账制定设计计划，未登记台账的设计员有权不予设计。
  • 改善类、通用类、设备辅具类等工装，可直接由需求部门经理审批通过后由提出人启动需求流程。
  • 非必要工装可驳回：若制作成本远大于使用价值（如产量 5 台以下，可由划线、零部件互配等方式加工装配的），工艺主管部门可驳回制作申请。
  • 需求描述必须清楚，必要时附图或上传图片说明。

3. 制作计划

生产管理部根据实物使用时间及所属项目零件加工计划制定加工计划；非项目工装按需求时间制定。计划下达后须在台账注明相关信息。

4. 工装设计

  • 对要求不合理、功能定义不清晰的申请，设计人员有权驳回。
  • 设计人员完成初步方案后须与申请人、使用人交流确认，再进行详细设计并上传图纸、启动工艺流程；重点工装（A、B 类）在制作过程中设计人员应配合协助现场制作并告知使用方法。
  • 台账由工装设计人员主导管理，各相关部门主动完善各自节点信息。
  • 工装设计每月 25 日（节假日顺延）更新台账，汇总各部门落实情况后反馈至各部门经理。

5. 受控工装图纸

资料室接收到图纸生效流程后，及时对图纸受控并下发至生产车间，完成后在台账注明信息。

6. 工装制作

  • 生产管理部门应明确制作责任主体，纳入本部门子计划；加工单位（含自制与委外）严格按图纸、技术要求加工，按正常产品流转、检验。
  • 设计或技术要求不明确时，加工单位应及时反馈相关人员进行确认或更改。
  • 成品工装由生产部门组织装配，必要时设计人现场指导，完成后转运至工装暂存区后报检。

7. 工装外购件

采购主管部门按物料清单进行外购件采购。

8. 工装检验

  • 质量主管部门依图纸对制作过程中的零件进行检验；重点工装（A、B 类及其他有必要的）可组织工艺、技术等部门共同检验；结果记录存档。
  • 发现不良及时通知设计人员到场处理，同时按《不合格品控制程序》发起《不合格品处理单》。
  • 检验合格后由生产主管部门办理入库手续，入库信息需注明检验时间、工装名称、图号、类别、使用项目等。
  • 库房及现场在用工装，由质量主管部门按台账注明的点检周期周期性点检并保存记录。
  • C 类工装不填写检验报告。

9. 入库和贮存

  • 仓储主管部门依据制作申请单和质量检验记录办理入库，并在台账注明入库日期。
  • 负责（不含量、检具）库存工装的贮存管理：平放、清理、转动部件与刀口涂润滑脂、标识清晰、工装遮盖。
  • 工装标识内容包括：工装编号、名称、图号、状态（待验证 / 合格 / 维修 / 报废等）；外协工装还需有制造厂家。
  • 新增、进出库、报废等信息变更时须主动更新台账。

10. 使用

  • 使用人员到仓储指定处领取，由仓储主管部门登记借用记录。
  • 使用前复核工装标识，检查各部件是否完好、有无变形；首件产品报检，合格后方可继续生产。因工装原因导致产品不符合要求时，按《不合格品控制程序》发起《不合格品处理单》并对工装评审处理。
  • 使用后使用部门应及时保养并退库，退库时登记检验结果。

11. 周期检定

  • 检定周期由「工装分类」确定。使用年限已超过寿命的工装，检定周期改为半年一次，经工艺人员和质量人员评估合格后方可继续使用。
  • 检定结果应记入系统检定记录，并上传检定报告等附件；系统要求检定时必须上传附件，以保证检定过程可追溯。
  • 检定不合格或待修的工装，系统自动将其状态置为「维修」。
  • 检定合格后应在台账更新相关信息。
  • C 类工装由车间线边自行管理。

12. 维护、保养

  • 库存货架工装由仓储管理人员按维护保养记录维保，填写记录后存档，由所属部门经理监督。
  • 现场存放工装由现场使用人员按维护保养记录维保，填写记录后存档，由所属部门经理监督。

保养周期：半年 / 次。点检作业内容：① 关节、滑动部位是否打油润滑；② 紧固件是否松动；③ 工装是否有裂纹、破损；④ 配件是否齐全。

13. 报废

  • 一次性工装领用使用完成后及时报废处理。
  • 仓储主管部门应每半年组织工艺、生产、质量等相关部门对库存工装集中评审是否报废。
  • 其他特殊情况需报废的，由所属或使用部门组织相关部门评审，通过后在系统提交报废审批。
  • 报废工装应及时处理、及时销账。

14. 考核

因工装制作进度滞后、工装遗失等不符合本管理办法的行为，依据台账落实情况按《工艺纪律管理办法》考核。
